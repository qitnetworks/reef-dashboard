# Windows — empieza aquí

1. Descarga **reef-dashboard-0.3.0-windows-x64.zip** desde Releases.
2. Haz clic derecho en el ZIP y selecciona **Extraer todo**.
3. Abre **Start Aquarium.exe** en la carpeta extraída. No necesitas instalar Docker ni Node.js.
4. Sigue el asistente: nombre, idioma, buscar y seleccionar dispositivos y conectar una tableta. Puedes empezar con la demo o solo el diario.
5. Conecta la tableta a la misma red doméstica y escanea el QR. Para otra tableta: **Ajustes → Conectar una tableta**.

Mantén el ordenador encendido y sin suspenderse. Después de reiniciar Windows, abre el acceso directo del escritorio. La tableta es la pantalla, no el servidor.

Elige un tema en **Ajustes → Temas** y guarda los cambios. Hay seis estilos con diferentes animaciones; usa efectos ligeros en tabletas antiguas.

El programa de inicio de la beta no tiene firma digital. No desactives la seguridad de Windows. Si se bloquea, comunica el mensaje exacto. Los códigos son privados, de un solo uso y válidos 10 minutos.
