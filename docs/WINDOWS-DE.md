# Windows — hier starten

1. Lade **reef-dashboard-0.3.1-windows-x64.zip** unter Releases herunter.
2. Klicke die ZIP rechts an und wähle **Alle extrahieren**.
3. Öffne **Start Aquarium.exe** im entpackten Ordner. Docker oder Node.js musst du nicht installieren.
4. Folge dem Assistenten: Name, Sprache, Geräte suchen und auswählen, Tablet verbinden. Du kannst mit der Demo oder nur dem Protokoll starten.
5. Verbinde das Tablet mit demselben Heimnetz und scanne den QR-Code. Weitere Tablets: **Einstellungen → Tablet verbinden**.

Der Computer muss eingeschaltet und wach bleiben. Nach einem Windows-Neustart öffnest du die Desktop-Verknüpfung. Das Tablet ist das Display, nicht der Server.

Wähle unter **Einstellungen → Designs** einen Stil und speichere ihn. Sechs Designs haben unterschiedliche Animationen; leichte Effekte eignen sich für ältere Tablets.

Der Beta-Starter ist nicht digital signiert. Deaktiviere den Windows-Schutz nicht. Wird der Start blockiert, melde die genaue Nachricht. Verbindungscodes sind privat, einmalig und 10 Minuten gültig.

DHCP funktioniert. Reserviere im Router eine IP für diesen Computer oder Server (DHCP-Reservierung), damit die Tablet-Adresse gleich bleibt; automatische IP-Vergabe eingeschaltet lassen. Der QR-Code nutzt die Heimnetzadresse. Bei einer Änderung Einstellungen am Computer erneut öffnen, neuen Code erstellen und die Tablet-Verknüpfung aktualisieren.
