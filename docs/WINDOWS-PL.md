# Windows — zacznij tutaj

1. Pobierz **reef-dashboard-0.3.0-windows-x64.zip** z sekcji Releases.
2. Kliknij ZIP prawym przyciskiem i wybierz **Wyodrębnij wszystkie**.
3. W rozpakowanym katalogu uruchom **Start Aquarium.exe**. Nie instalujesz Dockera ani Node.js.
4. Kreator poprowadzi Cię przez nazwę akwarium, język, wyszukanie i wybór urządzeń oraz połączenie tabletu. Możesz zacząć od demo lub samego dziennika.
5. Połącz tablet z tą samą siecią domową i zeskanuj kod QR. Kolejny tablet dodasz przez **Ustawienia → Połącz tablet**.

Komputer musi pozostać włączony i nieuśpiony. Po restarcie Windows otwórz skrót akwarium na pulpicie. Tablet jest ekranem, nie serwerem.

Motyw wybierzesz w **Ustawienia → Motywy**. Zapisz wybór. Masz sześć wyglądów z różnymi animacjami; starszy tablet może korzystać z lekkich efektów.

Program startowy wersji beta nie ma podpisu cyfrowego. Nie wyłączaj ochrony Windows. Jeśli instalacja jest blokowana, zgłoś dokładny komunikat. Kody parowania są prywatne, jednorazowe i ważne 10 minut.
