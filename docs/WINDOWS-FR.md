# Windows — commencez ici

1. Téléchargez **reef-dashboard-0.3.1-windows-x64.zip** depuis Releases.
2. Faites un clic droit sur le ZIP et choisissez **Extraire tout**.
3. Ouvrez **Start Aquarium.exe** dans le dossier extrait. Docker et Node.js ne sont pas nécessaires.
4. Suivez l’assistant : nom, langue, recherche et sélection des appareils, puis connexion d’une tablette. Vous pouvez commencer avec la démo ou le journal seul.
5. Connectez la tablette au même réseau domestique et scannez le QR code. Pour une autre tablette : **Réglages → Connecter une tablette**.

Gardez l’ordinateur allumé et éveillé. Après redémarrage de Windows, ouvrez le raccourci du bureau. La tablette sert d’écran, pas de serveur.

Choisissez un thème dans **Réglages → Thèmes**, puis enregistrez. Six styles proposent des animations différentes ; les effets légers conviennent aux anciennes tablettes.

Le lanceur bêta n’est pas signé numériquement. Ne désactivez pas la sécurité de Windows. S’il est bloqué, signalez le message exact. Les codes sont privés, à usage unique et valables 10 minutes.

DHCP fonctionne. Pour garder une adresse stable sur la tablette, réservez une IP pour cet ordinateur ou serveur dans le routeur (réservation DHCP) ; gardez l’attribution automatique. Le QR utilise l’adresse du réseau domestique. Si elle change, rouvrez Réglages sur l’ordinateur, générez un nouveau code et actualisez le raccourci de la tablette.
