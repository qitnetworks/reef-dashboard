# Reef Dashboard 0.3.0 — Beta

Free local aquarium dashboard with five languages, a setup assistant and six animated themes.

**Windows users:** download `reef-dashboard-0.3.0-windows-x64.zip`, extract it, and open **Start Aquarium.exe**. It includes its runtime. No Docker or Node.js setup required.

**Server users:** download `reef-dashboard-0.3.0-linux-amd64.zip`. Requires a Linux x64 host with Docker Engine and Compose. This is not a bootable VM image.

**Do not choose GitHub’s “Source code” downloads** to install the app. They contain only the public documentation repository.

The computer/server must stay on; tablets display the dashboard. This beta’s Windows launcher is unsigned. Equipment control remains in ReefBeat.

Before updating, export a backup from Data & backups. Keep your existing installation data and server configuration.

Assets: the two ZIPs above, their `.sha256` files, and `SHA256SUMS.txt`.
