# Reef Dashboard 0.3.1 — Windows beta hotfix

The Windows launcher now starts in English instead of following the Windows display language. After choosing a language in application settings, subsequent startup and stop messages follow that preference.

Tablet setup now explains how to keep a stable address with a DHCP reservation in your router. Pairing codes use the computer's detected LAN address, not localhost. DHCP itself is supported; after an IP change, reopen Settings on the computer, generate a new code and update the tablet shortcut.

Download `reef-dashboard-0.3.1-windows-x64.zip`, extract the entire ZIP, and open **Start Aquarium.exe**. Existing aquarium data and access settings are preserved. Export a backup from **Data & backups** before updating.

[Installation instructions in five languages](https://github.com/qitnetworks/reef-dashboard#readme).

This release is for Windows x64 only. Linux / Docker users can continue using the [0.3.0 package](https://github.com/qitnetworks/reef-dashboard/releases/tag/v0.3.0).

The launcher is still unsigned. The computer must remain switched on and awake for tablets to use the dashboard. GitHub's automatic **Source code** archives contain documentation only; use the named Windows ZIP above.
